# DeepSeek 鲸鱼娘桌宠皮肤 — 设计方案

> 2026-08-13 · 原创代码绘制（零外部素材引用）· 个人自用

## 1. 形象设定

参考社区鲸鱼娘共识（蓝发 + 女仆装 + 鲸鱼尾的"蓝发鲸鱼女仆"组合），**全部元素原创绘制**，不复制任何现有精灵图/像素图：

| 元素 | 设计 |
|---|---|
| 发色 | DeepSeek 品牌蓝 `#4D6BFE`，深蓝发梢，头顶呆毛 + 白色女仆发箍 + 蓝色蝴蝶结 |
| 脸 | 白肤 Q 版圆脸，大眼（黑瞳 + 白高光）、淡粉腮红、小微笑 |
| 服装 | 蓝白女仆装：蓝裙摆 + 白色围裙 + 白色领子 + 白袖手 |
| 尾巴 | 身后鲸鱼尾（深蓝 + 白腹 + 分叉尾鳍），**情绪摆动**（idle 慢摆 / run 快摆 / sleep 垂落） |
| 氛围 | 深蓝 `#4D6BFE` 主色系，硬边像素风（无抗锯齿） |

## 2. 技术规格

- **帧规格**：96×96 原生像素（与喵喵一致），8 列/行 → 行宽 768
- **Sheet**：768×768（8 行），`lossless=True` webp（防代际损失，管线同 derive-pet-rows.py）
- **落盘**：`~/.tokenicode/pets/deepseek-whale-girl/` + `~/.tokenicode.dev/` 双目录（一致性校验）
- **pet.json**：仿喵喵结构（`name/sprite/frame/states`），8 状态键

## 3. 状态清单（8 行，全键命中引擎 STATE_MAPPING）

| 行 | 键 | 帧 | 时长 | loop | 动画 |
|---|---|---|---|---|---|
| 0 | `idle` | 8 | 150ms | ✓ | 呼吸 bob ±2px、尾摆正弦、每循环末帧眨眼 |
| 1 | `run` | 8 | 120ms | ✓ | bob 3px、身体前倾 0.05rad、尾摆加快 |
| 2 | `sleep` | 4 | 600ms | ✓ | 闭眼弯线、scaleY 0.92 锚底压扁、尾垂落、bob 1px |
| 3 | `wave` | 4 | 150ms | ✗ | 右臂抬起 ±20° 摆动、眼睛笑弯 |
| 4 | `jump` | 6 | 130ms | ✗ | 弹跳弧线 −18px + 落地 squash 0.88 |
| 5 | `waiting` | 4 | 160ms | ✓ | 歪头 0.08rad、眼睛睁大（"···"由氛围层叠加） |
| 6 | `review` | 4 | 200ms | ✓ | 眼睛左右扫视（扫描线由氛围层叠加） |
| 7 | `failed` | 4 | 200ms | ✗ | 低头 0.06rad、嘴变 frown（红晕泪滴由氛围层叠加） |

> 氛围层（ambient.ts）已覆盖 dots/扫描线/泪滴/Zzz → 皮肤行**不重复绘制**这些元素，只画姿态。

## 4. 绘制架构（Python + Pillow，参数化）

```python
draw_scene(draw, frame, state, palette)  # 主入口：按状态取动画参数
  ├─ draw_tail(...)   # 后层：鲸尾多边形，控制点随 angle 摆动
  ├─ draw_body(...)   # 蓝裙(梯形+圆摆) + 白围裙 + 白领
  ├─ draw_head(...)   # 圆脸 + 蓝发帘 + 呆毛 + 发箍蝴蝶结 + 眼(开/闭/笑/wide/扫) + 腮红 + 嘴
  └─ draw_arm(...)    # 白袖手（wave 时右臂抬起，摆动角 ±20°）
```

- **动画参数表**：每状态一组 `(bob, tilt, squash, tail_angle, eye_style, mouth_style, arm)`，由 frame 索引的三角函数驱动（`sin(frame/8·2π)` 等，与引擎 idle 呼吸同频）
- **硬边像素风**：全部整数坐标矩形/多边形填充（Pillow 无抗锯齿），不加缩放——96×96 原生像素
- **防露底**：精灵内容距帧边界 ≥3px 边距；squash 锚底（下移不飘起）
- **眨眼**：idle 每循环帧 7 闭眼（1.2s 周期，与喵喵呼吸同节奏）

## 5. 管线与验证
