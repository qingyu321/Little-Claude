# Little Claude

Claude Code 桌面 GUI 客户端 — 基于 Tauri 2 原生构建，免安装便携版与安装版均在此仓库发布。

## 功能

- **多会话标签页** — 并发运行多个对话任务，后台会话不中断
- **文件浏览器** — 项目文件树、预览、编辑、拖拽附加到对话
- **Rewind 回退** — 基于 CLI 检查点恢复文件
- **斜杠命令与 Skills** — 内置命令 + 自定义命令 + 技能面板
- **多 Provider API 配置** — Anthropic / OpenAI 兼容 / 内置预设（DeepSeek、智谱 GLM、通义千问、Kimi、MiniMax），支持代理
- **多模态扩展** — 视频分析（ASR 转写 + 多模态识图交叉验证）、语音输入、动态壁纸
- **中英双语界面**、多主题、CLI 一键安装与环境部署

## 下载

请到 [Releases](https://github.com/qingyu321/Little-Claude/releases) 下载最新版本：

- Windows：便携版（单 EXE，免安装）/ 安装版（NSIS）
- macOS：dmg（Apple Silicon / Intel）
- Linux：deb / AppImage / rpm

历史版本（v1.0.1 ~ v1.1.0）的资源也保留在 Releases 中，可随时回退下载。

## 快速开始

1. 从 Releases 下载对应平台安装包（Windows 便携版解压即用）。
2. 打开 Little Claude，在设置中配置 API Provider（或使用已安装的 Claude Code CLI）。
3. 选择项目文件夹，开始对话。
